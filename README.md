# Rossmann Store Sales Forecasting

Forecast daily sales and customers for Rossmann stores up to six weeks ahead, and serve the forecasts in a web app.

## Setup
1. `pip install -r requirements-dev.txt`
2. Put train.csv, test.csv, store.csv and sample_submission.csv in `data/raw/`.
3. Run the notebook in `notebooks/`.

(Sections on reproduction, data and model retrieval and the app are completed in Section 12.)
